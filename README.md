# Meetbly Booking

WordPress plugin (Phase 1): embed your [Meetbly](https://meetbly.com) service booking widget via block, shortcode, or Elementor.

## Development

Plugin source lives in [`meetbly-booking/`](meetbly-booking/). See [`BUILD.md`](BUILD.md) for the full Phase 1 specification and constraints.

Install for local testing by copying or symlinking `meetbly-booking` into `wp-content/plugins/` and activating **Meetbly Booking** in the WordPress admin.
